# 教学管理工作台 · 技术架构确认文档

> 任务：物理教师专属「教学管理工作台」（Web + Android APK），本地部署，单用户。
> 本文档为设计阶段交付件，确认后按里程碑实施。本次自动执行先交付 M1。

## 一、现状分析

- 工作区为空目录（仅 `.agent_context`），无任何已有代码，属于全新项目，无历史包袱。
- 运行环境：Windows 11 + Node.js v24.14.1 + npm 11，可直接使用 workspaces monorepo。
- 需求已明确：技术栈、模块清单（P0/P1/P2）、UI 信息架构（底部 5 Tab）、里程碑（M1~M5）、验收标准均已给出，无关键缺口。
- 需注意的环境约束：
  - 局域网 HTTP 下 `getUserMedia` 不可用 → 拍照必须用 `<input type="file" capture="environment">`。
  - `better-sqlite3` 为原生模块，Node 24 下使用 v12.x 预编译二进制；安装失败时回退方案见「风险」。

### 技术选型确认

| 层 | 选型 | 说明 |
|---|---|---|
| 后端 | Fastify + better-sqlite3 | Fastify 内置 schema 校验与日志；SQLite 单文件零运维 |

| PDF 导出 | 前端生成（html2canvas/jspdf 或打印样式） | M2/M4 实施 |

## 三、数据库表设计（SQLite）

```sql
-- 系统设置（KV）：登录密码、auth token、AI 供应商配置、端口等
settings(key TEXT PRIMARY KEY, value TEXT NOT NULL);

-- 学生档案
students(id INTEGER PK AUTOINCREMENT, name TEXT NOT NULL,
  grade TEXT CHECK(grade IN ('高一','高二','高三')), school TEXT, textbook TEXT,
  phone TEXT, parent_wechat TEXT, avatar TEXT, note TEXT,
  status TEXT NOT NULL DEFAULT '在读' CHECK(status IN ('在读','停课','结课')),
  created_at TEXT NOT NULL);

-- 课时包（购买记录）
hour_packages(id INTEGER PK AUTOINCREMENT, student_id INTEGER NOT NULL REFERENCES students,
  hours INTEGER NOT NULL, amount REAL NOT NULL DEFAULT 0,
  purchase_date TEXT NOT NULL, note TEXT, created_at TEXT NOT NULL);

-- 缴费流水
payments(id INTEGER PK AUTOINCREMENT, student_id INTEGER NOT NULL REFERENCES students,
  amount REAL NOT NULL, method TEXT, paid_at TEXT NOT NULL,
  package_id INTEGER, note TEXT, created_at TEXT NOT NULL);

-- 每周固定课表（weekday: 0=周日 … 6=周六）
schedules(id INTEGER PK AUTOINCREMENT, student_id INTEGER NOT NULL REFERENCES students,
  weekday INTEGER NOT NULL CHECK(weekday BETWEEN 0 AND 6),
  start_time TEXT NOT NULL, end_time TEXT NOT NULL, note TEXT, created_at TEXT NOT NULL);

-- 签到记录（到课自动扣 1 课时并写 payments 无关的扣课时流水）
attendance(id INTEGER PK AUTOINCREMENT, student_id INTEGER NOT NULL REFERENCES students,
  date TEXT NOT NULL, status TEXT NOT NULL CHECK(status IN ('到课','请假','缺勤')),
  schedule_id INTEGER, deducted INTEGER NOT NULL DEFAULT 0, note TEXT, created_at TEXT NOT NULL);

-- 学情日志（核心表；images/ai_result 为 JSON 文本；M1 手动版不填 ai_result）
study_logs(id INTEGER PK AUTOINCREMENT, student_id INTEGER NOT NULL REFERENCES students,
  date TEXT NOT NULL, type TEXT NOT NULL CHECK(type IN ('上课','作业','考试','其他')),
  content TEXT NOT NULL, images TEXT NOT NULL DEFAULT '[]',
  ai_result TEXT, ai_generated INTEGER NOT NULL DEFAULT 0,
  next_class_key TEXT DEFAULT '',        -- 下次课重点（今日工作台展示）
  created_at TEXT NOT NULL);

-- M2 预留（本次只建不实现业务）：错题 mistakes、AI 供应商 providers、AI 用量 ai_usage
```

剩余课时 = `SUM(hour_packages.hours) - SUM(attendance WHERE status='到课' AND deducted=1)`，列表/工作台剩余 ≤3 红色预警。

## 四、关键数据流

1. **登录**：`POST /api/auth/login` 校验密码（首启默认 `admin123`，存 settings 可改）→ 签发随机 token 存 settings → 前端 Zustand 持久化，fetch 封装自动带 `Authorization: Bearer`。
2. **记学情（M1 手动）**：学生详情 → 学情日志 → 新建（日期/类型/内容/下次课重点）→ `POST /api/students/:id/logs` → 时间线倒序展示。
3. **上课扣课时**：今日课表卡片「签到」→ `POST /api/attendance`（status=到课 → 写 attendance，deducted=1）→ 学生剩余课时联动刷新，≤3 全局红色提示。
4. **M2 AI 流水线（规划）**：前端压缩图片（长边 1600 / q0.8）→ multipart 上传 → 视觉模型（qwen-vl-max）按 `packages/shared` 中 prompt + JSON Schema 输出结构化结果 → 后端 zod/手写校验，失败重试 ≤2 次 → 返回初稿 → 教师在「结果编辑页」逐项确认 → 才写 study_logs + mistakes，打 `ai_generated=1`，并记录 token 消耗到 ai_usage。

## 五、REST 接口清单（M1 范围，统一前缀 /api）

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /api/auth/login | 登录取 token |
| GET | /api/auth/me | 校验 token 有效性 |
| GET/POST/PUT/DELETE | /api/students[/:id] | 学生 CRUD（列表带剩余课时） |
| GET/POST/DELETE | /api/students/:id/packages | 课时包 |
| GET/POST | /api/students/:id/payments | 缴费流水 |
| GET/POST/DELETE | /api/students/:id/schedules | 每周固定课表 |
| POST | /api/attendance | 签到（到课自动扣课时） |
| GET | /api/students/:id/logs | 学情日志时间线 |
| POST/DELETE | /api/logs[/:id] | 手动记学情 |
| GET | /api/today | 今日课表、签到状态、待办、剩余课时预警、下次课重点 |
| GET/PUT | /api/settings | 端口/密码/AI 配置（key 值 GET 时脱敏返回） |

## 七、风险与对策

| 风险 | 对策 |
|---|---|
| better-sqlite3 原生模块安装/编译失败 | 优先 v12.x 预编译；失败则提供最小编译指引（VS Build Tools）；最终兜底改 node:sqlite（Node 24 内置）并同步告知 |
| AI 输出 JSON 不合法/编造 | 严格 Schema 校验 + 重试 2 次；识别不清进 `unrecognized` 并标「待确认」，校验失败不入库 |
| 学生隐私数据出网（AI 分析传图） | 设置页显著提示；图片先压缩；数据仅存本机；导出备份提醒加密保存 |
| 局域网 HTTP 限制（getUserMedia/ServiceWorker） | 拍照用 `<input capture>`；P2 相关功能不依赖 SW |
| Windows 防火墙拦截局域网访问 | start.bat 首次运行打印 `netsh advfirewall firewall add rule` 放行命令 |
| 端口冲突 | 端口可在设置中修改，启动时检测占用并提示 |
